## 适用范围（v4 新增，动手前先确认）

**本流程只适用于：A 股「非 ST」的普通个股**——沪深主板 / 创业板 / 科创板 / 北交所，
上市满 150 个交易日、正常交易、未被实施风险警示。

| 类型 | 是否适用 | 说明 |
|---|---|---|
| 主板 / 创业板 / 科创板 非 ST | ✅ | 主战场 |
| 北交所 非 ST | ⚠ 谨慎 | 涨跌停 ±30%，**规则库的回测样本不含北交所**，判据无统计支撑 |
| **ST / \*ST / 退市整理期** | ❌ **不适用** | 见下，**7 条判据直接失效** |
| 次新股（上市 <150 交易日） | ❌ | 缠论需 250 根，指标需 ≥60 根；P0 数据长度检查会拦下 |
| 长期停牌 / 复牌未满 20 日 | ❌ | 量价、均线、资金流全部失真 |
| B 股 / 港股 / 美股 | ❌ | 数据源与规则库都不覆盖 |

### 为什么 ST 不适用（不是"没做"，是"做了会错"）

| 环节 | ST 股上会发生什么 |
|---|---|
| **P0 复权** | 主板 ST 涨跌停 **±5%**，若按 10% 判跳空，**5%~10% 的除权会被漏检 → 前复权失效**。已修（`qfq.limit_of` 加 ST 分支），但这属于"修好了也不该用" |
| **P2 技术** | 5% 涨跌停导致**一字板无法成交**，量价关系完全变形；"缩量""放量"在这些票上没有原有含义 |
| **P3 基本面** | 财务类退市标准（营收<3亿 且 扣非<0 连两年 / 净资产为负 / 审计非标）意味着**"成长性·质量·估值"这套框架失去前提**——真问题是"会不会退市"，不是"贵不贵" |
| **P3 估值** | PE/PB 在退市预期下没有意义，分子分母都可能归零 |
| **P3 一致预期** | ST 股基本**无卖方覆盖**，`data_consensus` / `data_report` 返回空或极少 → 一致预期校验、`reports_dist` 全部失效 |
| **P4 资金** | ① ST 股通常**被调出两融标的** → 融资拥挤度规则失效；② **不在陆股通标的** → 北向规则失效；③ 机构受限/禁入，主力是游资，**"超大单/大单"的分层含义与正常股不同** |
| **P5/P5.5 赔率与类型** | 规则库 universe 是**当前仍有数据的 4,973 只普通股**，**ST 不在回测样本内** → 强跌反弹 +0.97%、深回踩 +0.07% 这些数字**对 ST 没有任何统计效力** |

> **一句话**：ST 不是"难一点"，是**判据体系的前提被抽掉了**。
> 遇到 ST，正确动作是**停止，并明确告知"本流程不适用于 ST"**，而不是降级套用。

### 识别方法（P0 的第一个动作）

```python
import sys; sys.path.insert(0,'common')
import qfq
name = qfq.load_raw('600089', 1)[-1].get('name')   # 从日K拿名称
qfq.is_st(name)                                  # True → 停止，不套流程
qfq.limit_of('600089', name)                     # 顺带确认涨跌停口径 0.05/0.10/0.20/0.30
```

**判定口径**：名称含 `ST` / `*ST` / `SST` / `S*ST` / `退` → 视为风险警示，停止。
**名称可能滞后**（撤销 ST 改回原名有一两天延迟），**以交易所公告为最终依据**。

> **v4 补记（2026-11-09）**：`qfq.limit_of()` 此前**没有 ST 分支**，主板 ST 一律按 10% 处理。
> 任何一次误跑到 ST 股上，复权都会静默出错（5%~10% 的除权漏检 = v3 那个 31%~108% 偏差的复发路径）。
> **已修**：新增 `is_st()` + `limit_of(code, name)`，`breakout_scan.py` 同步修；
> 单元测试 11 例全过（主板 ST 5% / 创业板·科创板 ST 20% / 北交所 ST 30% / 非 ST 10%）。

### P0 · 数据闸门

| # | 检查项 | 方法 | 不通过的处置 |
|---|---|---|---|
| **0** | **是否 ST / 退市整理**（v4 新增，第一道） | `qfq.is_st(名称)`；名称含 `ST`/`*ST`/`SST`/`退` | **停止**，明确告知"本流程不适用于 ST"，**不降级套用**（原因见「适用范围」7 条） |
| 1 | stockdb 是否连通 | `cmd=vals&t=日k:<纯数字>` 返回 200 | 回退 easy-tdx；两者都不通 → 停止，不编造 |
| 2 | 最新交易日 | 取 stockdb 日K最后一根 | 标注 `dataAsOf`；需要当日盘中再补 easy-tdx |
| 3 | 数据长度 | ≥ 150 根（缠论需 250、三级均线需 250） | <150 → 停止（次新/停牌）；150~250 → 降级为"仅均线/指标"，**不出缠论结论** |
| 4 | **是否除权跳空** | 扫描单日涨跌幅 > `limit_of(code, name) + 0.5%` | easy-tdx 原生 QFQ 已规避；stockdb 路径走 `qfq.adjust_recs()`（跳空推断误差 ±3%） |
| 5 | **停牌 / 复牌** | 最近 20 日是否有 >5 日连续缺K | 有 → 停止或标注"复牌不足 20 日，量价失真" |
| **6** | **分红方案逐条对账（v4.3 强制）** | 拉 `data_dividend(years≥6)`，与 `div_cache.json` **逐条比对日期与金额**；并验证每个除权日 `实际比值 / 理论因子 = 1 + 当日 pct_chg` | 缺任一年度 → **补录后再分析**，不得进入 P2 |

> **⚠ P0 附则：`needs_div()` 返回 False 不等于「不需要复权」（v4.3，工程缺陷 #10）**
>
> **踩坑实录（长江电力 600900 2026-11-09）**：`needs_div('600900')` = **False**，看起来复权链干净。
> 但这个函数只检测 **> `limit_of()+0.5%`（主板 10.5%）** 的跳空，而长江电力的**现金分红只造成 0.8%~3.5% 的除权跳空**，
> **永远不会触发阈值** —— 对高股息、低波动、只现金分红不送转的股票，它**恒为 False**，与缓存有没有数据无关。
>
> 逐条对账才发现：6 年 **8 次分红**（2021 起每年年报分红，2025 起增加中期分红），
> 累计前复权因子 **0.8171（−18.29%）**。若 `div_cache` 缺 600900，所有均线、回撤、分位、缠论会**静默错 18.29%**。
>
> **固定纪律**：
> 1. **`needs_div()` 只能用来"发现大比例送转"，不能用来"证明不需要复权"**。它返回 False 时，第 6 项仍必须做。
> 2. 高股息标的（股息率 >2%、或已知每年分红）**强制拉 `data_dividend` 逐条对账**，不依赖跳空扫描。
> 3. 对账通过的标准：方案条数一致 + 金额一致 + 每个除权日 `实际比值/理论因子 − 1 = 当日 pct_chg`。
> 4. **"年报分红 + 中期分红"双轨制**要特别注意：滚动 12 个月窗口会重复计入或漏计，
>    算历史股息率分位时**不要**用滚动 TTM 口径（见 §P3）。

> **血泪教训（2026-10-19）**：001309 未复权被误读为"单日 −27.3%"，实为「10派15元转4股」。全市场 16.2%（902/5577）有此问题。
>
> **补充（2026-11-09）**：第 4 项的分母口径以前是写死的板块涨跌停，**漏了主板 ST 的 ±5%**。
> 现在统一走 `qfq.limit_of(code, name)`，**必须把名称一起传进去**，否则 ST 股会静默漏检 5%~10% 的除权。
> 另外实测**特变电工 600089 有 7 处 >10% 跳空**（2000~2023，最近一处 2023-07-18 −27.06%），
> 全部落在 2023-07 之前，**不影响近 250 日分析**，但说明"这只票 0 处跳空"的说法是错的——**别信印象，每次扫**。

### P1 · 量化池交叉 + 行业定位

**第一步：池子标签**

| 池子         | 逻辑                                            | 样本外表现                                    | 命中意味着     |
| ---------- | --------------------------------------------- | ---------------------------------------- | --------- |
| **深回踩**    | 宽箱体>25% + 深回踩>15% + 量比0.9~1.2 + 收阳 + 收盘位置≥50% | **+0.07%（t=0.64）**<br />精确数据下**已淘汰** | 唯一在样本外仍为正 |
| V2 三角      | 收敛 + 顶点临近 + 放量突破                              | 未验证                                      | 形态候选      |
| V4 收敛      | 低点抬高 + 振幅收缩 + 量缩                              | 无增量                                      | 仅观察       |
| 困境反转 v1/v2 | 7 条 / 9 条基本面+超跌                               | 未验证                                      | 反转候选      |
| 突破池        | 整理 + 带量突破 + 不追高                               | **−0.56%（t=−3.83）**                      | **反向指标**  |

**第二步：行业定位（v2 新增，走 easy-tdx）**

```
industry_of(code)      → 真实行业（600060 = 黑色家电）
peers_industry(code,5) → 同行业中市值最接近的 5 只
```

**用途**：区分「公司问题」还是「行业问题」。例：四大家电 Q3 扣非全部转负 → 是行业性需求疲弱，不是单家公司经营失误。

> **★ 同业的正确用法（v4 补充，2026-11-09）**：不只是"看同业 PE 贵不贵"，更要看**同期间的同向指标变动**。
> 宁德案例：单看它毛利率 −2.59pt 像"公司变差"；把亿纬（−1.50pt）、国轩（−1.33pt）摆在一起，
> 才看出是**全行业价格战**。**单票的任何"恶化"，都要先问一句：同业同期是不是也在恶化？**
> 尤其是毛利率、营收增速、扣非增速这三项——**这三项的同业对比，能挡掉一半的误判。**

### P2 · 技术结构

#### 2.0 级别纪律（v4 强制，2026-11-09 新增）

**日 / 周 / 月 三级全做，不许只做日线。**

| 情形 | 必做级别 | 原因 |
|---|---|---|
| 默认 | **日 + 周** | 结构定位够用 |
| **距 250 日高跌幅 > 30%** | **日 + 周 + 月** | 大级别破位与"大级别突破后回调"是两件事，只有月线能分 |
| **准备判断"结构性下跌"** | **必须月线** | 没有月线就不要下这个结论 |

> **踩坑实录（宁德时代 2026-11-09）**：初版只做日线+周线，因周线跌破中枢下沿 26.6% 判"结构性下跌"。
> 补做月线后发现：**价格 254.22 仍在月线中枢上沿 213.50 之上 19.07%**，
> 是 4 年半长期箱体（166.80~213.50）突破 468.75 后的回调，**长期结构根本没破**。
>
> **原因**：均线（MA250）与中枢是两个工具——均线说"过去一年平均成本在哪"，中枢说"结构区间在哪"。
> 宁德 MA250 在 371.26（跌破 31.5%），但月线中枢上沿只有 213.50（还在上方 19%）。
> **只看均线会把"高位回调"误判成"长期破位"。**

#### 2.1 缠论（czsc）

| 输出项               | 判读意义                |
| ----------------- | ------------------- |
| 笔/分型/中枢数          | 中枢<3 笔 → 标记"未成立"    |
| 最近中枢 ZD / ZG / ZZ | 支撑、压力、中轴            |
| 当前位置（上/内/下）       | 强弱第一层判断             |
| 最后一笔方向/幅度/线性度     | 线性度<0.3 = 结构不干净     |
| **进行中的笔（ubi）**    | 周/月线必看，否则用老笔        |
| 力度比（本笔/前同向笔）      | <0.9 疑似背驰；>1.2 趋势加速 |
| 当前腿回吐 %           | >50% 该笔可能结束         |

#### 2.2 指标

| 指标                   | 阈值关注                    |
| -------------------- | ----------------------- |
| MA5/10/20/60/120/250 | 站上几条、距年线多远              |
| MACD                 | DIF vs DEA、柱扩张/收缩、**DIF 在零轴上方还是下方** |
| RSI6 / RSI14         | <35 超卖、>70 超买           |
| **ADX**              | **<20 无趋势（箱体）；>40 强趋势** |
| **ADX 的 DI 方向（v4 强制）** | **+DI −（−DI）>10 才算方向明确；差值 <5 视为"强趋势但方向未定"** |
| ATR%                 | >5% 高波动，止损必须放宽；**<3% 为低波动（止损不易被日内噪音扫）** |
| 量比                   | >1.5 放量、<0.8 缩量         |

> ⚠️ **v4 新增：ADX 必须配 DI 一起读，否则会把完全相反的两只票混为一谈。**
> 下表为 2026-11-06 收盘实测（TA-Lib ADX14 / DI14）：
>
> | 案例 | ADX | +DI / −DI | 差值 | 真实含义 |
> |---|---|---|---|---|
> | 宁德时代 300750 | **40.9** | **27.5 / 28.4** | **−0.9** | 趋势极强，但**空头仍主导** → 缩量反弹是弱反弹 |
> | 阳光电源 300274 | 34.6 | 36.4 / 17.2 | +19.2 | 强趋势 + 多头，但已连涨 5 日（+25.6%）→ 追高风险 |
> | 特变电工 600089 | **20.8** | **35.0 / 14.8** | **+20.2** | 趋势刚成立，**多头压倒性** |
> | 欣旺达 300207 | **15.7** | 27.3 / 19.3 | +8.0 | **无趋势**（箱体），短期多头只是反弹 |
>
> **四只票四种组合，只看 ADX 会把它们全排错序**：
> 宁德 ADX 最高（40.9）但方向向下；特变 ADX 只有 20.8 但方向最明确；
> 欣旺达 ADX 15.7 意味着"任何趋势判断都不成立"——**这时候不该谈方向，该谈区间**。
>
> 判读顺序固定为：**① 先看 DI 差值定方向 → ② 再看 ADX 定强度 → ③ ADX<20 时方向结论作废**。

> ⚠️ **v4 新增：MACD 的零轴位置比"金叉"更重要。**
> 四只票里三只（宁德 DIF **−14.46**、阳光 −1.70、欣旺达 −0.23）都是"零轴下方深水区金叉"，
> 只有特变（DIF **+0.049**、DEA −0.146）真正翻上零轴。**零轴下方的金叉只是修复，零轴上方的金叉才是趋势。**
> 注意特变的 DIF 只比零轴高 0.049（0.26% of price），是"刚翻上来"，**随时可能掉回去 → 需要连续 2~3 日确认**。
