## 7. 已知不足

### ✅ v2 → v3 已解决

| 问题 | 解决方式 |
|---|---|
| **前复权失真**（历史价偏差 31~108%） | 改用 easy-tdx 原生 QFQ；个股/摘要默认精确，回测支持 `SRC=tdx` |
| **赔率虚高**（600089 算出 4.68:1，实际 0.75） | `_up_targets` 候选池取最近阻力 + 赔率分母改用实际止损距离 |
| **退出规则空白**（只有"持有 20 日"） | `exit_backtest` 33 组对照 → P5.6 定稿 −10% 止损 |
| **组合层空白**（只有单笔超额） | `portfolio_backtest` 净值/回撤/Sharpe |
| **日报噪音 882 只** | `daily_digest` 收口成 A/B/C 三档 |
| **数据层无超时/熔断** | `tdx_src` 看门狗 25s + 熔断 180s |
| **缓存无限堆积**（338MB/天） | `cleanup.py` 自动保留 2 个 |

### 🔴 仍缺（P0 级，影响结论可信度）

1. **没有实盘 / 纸面跟踪**。所有结论都是回测，样本 3.2 年、只覆盖一种市场环境。
   建议先纸面跟 1~2 个月再决定是否投入真金。
2. **幸存者偏差**。universe 只含「当前仍有数据」的 4,973 只，退市股池不完整；
   亏损退市的票不在样本里，会让所有策略看起来比实际好。
3. **OOS 只切一次**。`rule_lab` 按中位日期切一刀，没有多折 / 滚动验证，单次分割存在偶然性。
4. **规则库不含 ST、也不含北交所**（v4 新增，2026-11-09）：
   回测 universe 是普通 A 股，ST 与北交所（±30% 涨跌停）都不在样本内。
   → **所以这两个群体没有任何统计支撑**，本流程的"适用范围"把它们排除了。
   → 反过来说：**如果你要在 ST 上做研究，得单独建一套规则库，不能借用这里的数字。**
5. **ST 的退市判据完全没有建模**：财务类退市（营收<3亿+扣非<0 连两年 / 净资产为负 / 审计非标）、
   面值退市（<1 元）、市值退市——本流程一个都没写。**这是刻意不写，不是遗漏**（见「适用范围」）。

### 🟡 仍缺（P1 级）

- **PE 时间序列分位**（只有全市场截面分位，没有「这家公司历史上现在处于什么位置」）
- **PE 截面分位在分母塌陷时完全失效**（v4 新增）：欣旺达 PE 128.9 却显示"全市场 45% 分位"，
  因为全市场 PE 中位数本身也被亏损股推高了。**处置：分母塌陷（净利 <0 或同比 −80% 以上）时，
  直接作废 PE 分位，改用 PB + 一致预期 PE。**
- **一致预期里含一次性收益，无法自动剥离**（v4 新增）：欣旺达 2026E 20.86 亿，
  但 Q4 需要 14.7 亿（Q3 只有 1.06 亿，13.9 倍），差额主要来自欣旺达动力出表的重估收益。
  **处置：一致预期要和 Q3 年化做交叉校验，偏离 >50% 就标"预期含非经常性"，不作为估值依据。**
- **事件面完全依赖人工检索，未自动化**（v4 新增）：P3.5 现在是手工调 `data_news_search` + 扫研报标题，
  四票里三票的关键结论都来自这一步（特变的公允价值、阳光的储能毛利、欣旺达的出表）。
  **风险：漏检即结论错。** 暂无法自动化（需要 NLP 判断"这条新闻是否解释了这个财务异动"）。
- **龙虎榜未接**（个股非异动时多为空，价值有限）
- **行业口径不一致**：MCP 说「传媒」，easy-tdx 说「出版业」，同业对比可能选错公司（报告已加标注）
- **Jev 置信度有随机性**：同一份数据两次跑，强跌反弹 0.32 vs 0.17。**可用来定权重，不适合卡边界**
  → v4 对策：看**四象限**（§P6），不看单次分数；置信 <0.5 一律标"需人工复核"
- **`data_consensus.institutionCnt` 系统性返回 0**（v4.5）：九票里 4 只为 0，含万亿市值龙头与 8 家券商覆盖的票。
  → 已改用 `data_report` 列表 + 真实研报做覆盖度依据；**该字段本身待数据源修复，不在本地可解**
- **扣非 PE 的分位无法直接算**（v4.5）：全市场截面分位只有归母口径的 PE，
  `valuation_pct` 不提供扣非口径 → 中微、瑞芯微这类必须"作废归母分位"的票，
  **只能报扣非 PE 绝对值 + PB 分位，没有"扣非 PE 历史分位"这个数**。
  → 处置：报告里明确标"扣非 PE 无分位参照"，不要用归母分位替代
- **PEG 依赖增速假设，无法证伪**（v4.5）：瑞芯微 PEG 0.79 全靠 +70.9% 增速，回落到 30% 即变 1.88。
  → 处置：必须给增速回落敏感度表；**PEG 只能作为"增速可持续时的参考"，不能作为估值结论**
- **并表年份的 PE/PB 时间序列分位不可构造**（v4.6）：中国船舶 2025Q3 吸收合并中国重工，
  股本 52.22 亿 → **75.26 亿股**跳变，EPS_TTM 跨断点不可比；NAPS 在 2025-03/06 为未重述口径（11.63/11.79）、
  2025-09 起为重述口径（18.75+），**PB 序列不连续**。
  → 处置：**并购年份直接标"分位不可得"**，改用「绝对 PE/PB + 同业横向 + 一致预期 PE」三件套；
  **禁止**用未重述的期次拼一条序列去算分位（会得到假分位）
- **合同负债科目容易被"净现金"叙事吃掉**（v4.6）：见 §5.5 #12。
  → 处置：凡 `合同负债/货币资金 > 50%` 的标的，估值章节**第一句话就要写清"现金对应预收款"**

### 🟢 仍缺（P2 级）

- **低波动组（ATR% 0.8~1.5）没有独立回测**，只有形态识别
  → v4 发现这个问题比预想重要：特变 ATR 2.62%（四票里唯一 <3%）导致 2×ATR 止损只有 5.24%，
  **贴着日常噪声，会被随机波动打掉**。而高波动股 2×ATR 已有 9~11%，跟 −10% 差不多，不存在这个问题。
  **结论：止损口径之争对高波动股是伪问题，对低波动股是真问题。低波动组必须单独回测（用 10% 宽止损 vs 2×ATR）。**
- **A 档 6 只 / B 档 15 只 / 单池 2 只** 都是硬编码，没有统计依据
- **横向对比（P7）的排序规则未经回测**：逐层筛选的四层阈值（负债率 70%、OCF/NP 1.0）是经验值，
  四票样本太小，无法验证分层是否真的带来超额。
