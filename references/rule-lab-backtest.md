## 3. 规则库与验证（方法论，支撑第 2 章）

### 3.1 规则实验室：新增规则的唯一入口（`rule_lab.py`）

上面两张表是**一次性的结论**。为了让规则库不再"越积越多没验证过的品种"，已固化为模板：  
**任何新进场规则必须先注册、再自动跑完「回测 → Jev 复审 → 裁决」三道关，才允许写进 P5.5。**

```bash
python rule_lab.py --all             # 全跑，刷新注册表
python rule_lab.py --run <key>       # 只跑新增那一条
python rule_lab.py --list            # 看注册表当前状态
```

新增一条：在 `RULES` 里加一行

```python
"my_rule": {
    "name": "我的新规则",
    "polarity": +1,                  # ★ +1 进场型 / -1 回避型（判反会把好规则淘汰）
    "fn": lambda x: (x["c"] > x["zg"]) & (x["vr"] >= 1.2) & x["valid"],
    "def": {"触发": "...", "止损": "...", "持有": "...", "仓位": "..."},
},
```

`ctx` 可用字段：`o/h/l/c/v/vr/zg/zd/ma20/ma60/ma250/adx/rsi6/hi120/fx/width/depth/cpos/prev_above/valid`。

**自动裁决规则（写死在代码里，防止自己骗自己）**

| 条件                         | 裁决                     |                               |                     |
| -------------------------- | ---------------------- | ----------------------------- | ------------------- |
| `mean × polarity ≤ 0` 或 \` | t                      | < 2\`                         | ❌ 淘汰（统计不过关，语义再好也不用） |
| 方向正确 + \`                  | t                      | ≥ 2\` + Jev 置信 ≥0.5 + 健全度 ≥60 | ✅ 常规仓位              |
| 方向正确 + \`                  | t                      | ≥ 2\` 但 Jev 置信 <0.5           | ⚠️ 小仓（统计有效但语义无把握）   |
| `中位数 < 0` 且 `胜率 < 50%`     | 附注「**靠右尾**」→ 必须分散 + 止损 |                               |                     |

**★★ 2026-11-05 用精确数据复跑：结论方向不变，深回踩彻底归零**

发现前复权失真（§3.14）后，用 easy-tdx 原生 QFQ 全市场重跑（`SRC=tdx`，5220 只）：

| 规则 | 近似数据（stockdb+qfq） | **精确数据（easy-tdx）** | 变化 |
|---|---|---|---|
| 箱体回踩（浅） | −0.90%（t=−8.25） | −0.77%（t=−7.18） | 略好 |
| **深回踩** | **+0.18%（t=1.51）** | **+0.07%（t=0.64）** | **彻底归零** |
| 中枢上沿突破 | −0.80%（t=−10.26） | −0.82%（t=−11.31） | 一致 |
| 趋势突破 | −0.42%（t=−2.74） | −0.56%（t=−3.83） | 略差 |
| 趋势回踩 | −0.59%（t=−10.44） | −0.60%（t=−11.43） | 一致 |
| 高位派发（回避） | −0.64%（t=−5.08） | −0.72%（t=−6.06） | 略强 |

**三条结论：**

1. **所有规则的符号方向都没变** —— 说明此前基于近似数据的判断在方向上是可靠的，「回踩/突破买入在 A 股负期望」这条主线成立。
2. **深回踩从 +0.18%（t=1.51）掉到 +0.07%（t=0.64）** —— 证实了「那个薄优势本身就是复权噪声」的推断。
   现在全库只剩 **1 条正超额规则**：强跌反弹 +0.97%（t=29.7），仍靠右尾（中位 −1.19%、胜率 44.7%）。
3. **回测可复现**：两次独立取数（一次走缓存、一次重新全量取）跑出的数字**完全一致**；
   但 Jev 置信度有波动（强跌反弹 0.32 → 0.17），属模型随机性，不影响裁决档位。

**缓存注意**：`_kline_qfq_<日期>.pkl` 每天约 **338 MB**，建议只保留最近 2~3 个交易日。

### 3.2 闸门增量测试：过滤器到底有没有用（`--gate-test`）

`daily_digest.py` 里那套阈值（2 亿成交额、ADX≥20、不追高、收盘≥40%）原先全是拍脑袋定的。
`rule_lab.py --gate-test <规则>` 把它们逐个叠加到基准信号上，看 OOS/t 变好还是变坏：

```bash
python rule_lab.py --gate-test deep_pull    # 深回踩
python rule_lab.py --gate-test downtrend    # 强跌反弹
python rule_lab.py --gate-test ema_pull     # 通用回踩模式
```

**结果（持有 20 日，双边成本 0.2%，vs 原版 OOS 差值）**

| 闸门 | 深回踩 | 强跌反弹 | 通用回踩 | 判断 |
|---|---|---|---|---|
| **均额≥1亿** | −0.53pt | −0.28pt | −0.27pt | ❌ 有害 |
| **均额≥2亿** | **−1.02pt** | −0.30pt | −0.52pt | ❌ **有害（且高度一致）** |
| 均额≥5亿 | −1.59pt | −0.19pt | −0.55pt | ❌ 更糟 |
| 不追高 | 0.00pt | 0.00pt | 0.00pt | ⚪ 空转 |
| **ADX≥20** | **+0.22pt** | 0.00pt | −0.07pt | ✅ 只对深回踩有效 |
| 收盘≥40% | 0.00pt | −0.08pt | −0.03pt | ⚪ 空转 |

**三条结论（都跟直觉相反）**：

1. **流动性门槛在所有信号上都是负贡献，方向高度一致**（−0.30 ~ −1.02pt）。
   它对**降噪**有用，对**收益**有害 —— 因为超额集中在小票，而那些票你实际买不到。
   → 结论不是"去掉门槛"，而是"承认门槛后的数字才是真实可实现的"。
2. **深回踩加 2 亿门槛后 OOS = −0.84%（t=−5.14）**。它的"优势"完全来自流动性折价。
   → 已在 `daily_digest.py` 给深回踩持仓挂 ⚠ 警示，请当**观察**不当买入依据。
3. **ADX≥20 是唯一有效的闸门，但只对深回踩有效**（+0.22pt，t 1.51→3.07）。
   所以深回踩已单独开 `deep` 通道（= 贴支撑 + ADX≥20），震荡池仍走 `revert`（ADX<20 是它的定义）。

**⚠ 一个必要的自我修正**：趋势通道的 ADX≥20 闸门在统计上 **−0.07pt，几乎无增益**。
它当初是为了纠正「600060 箱体票被趋势逻辑误判」而加的，属于**语义合理性**修正，不是统计优化。
两者要分清：前者防止明显错误，后者提升期望。不要拿"我已经过滤了"当"我提高了胜率"。

**通用回踩模式本身是负的**：`站上MA60 + 回踩MA20 + 收阳 + 缩量` 在 31.7 万样本上 OOS **−0.57%（t=−18.2）**。
注意这只是 EMA 系统的**粗略近似**（不含 Supertrend 方向与 EMA10/21 结构），不能据此判 EMA 系统死刑，
但它再次印证了「回踩买入/突破买入在 A 股是负期望」这条主线。

### 3.3 退出规则回测：止损在保护还是在伤害

整条链路此前到「A 档」就断了——唯一的退出规则是「持有 20 日」，没有止损、没有止盈。
「该不该止损」这件事完全没有数据支撑。现已补上：固定同一批进场信号，只换退出规则。

**方法纪律（这里最容易写错）**

- 买点：信号日次日开盘（与 rule_lab 一致，无未来函数）
- 止损：按**盘中最低价**触发，成交价取 `min(开盘价, 止损价)`——跳空低开按开盘价成交，偏保守
- 基准：**按 (交易日, 持有天数) 二维聚合**的全市场平均。拿单只票自己的收益当基准是错的；
  拿固定 20 日基准去比 13 日就卖出的规则也不公平
- 完整结果见 `docs/退出规则回测.md`

**核心结论：33 组组合，零个 ✅**

| 信号 | 纯持有20日超额 | 最好退出 | 结论 |
|---|---|---|---|
| 强跌反弹 n=146,979 | **+0.94%**（t=30.8） | 持有30日 +1.06% | 止损全部 ⚠打到负/变差 |
| 深回踩 n=32,650 | **+0.25%**（t=3.0） | 持有10日 +0.12% | 所有退出都打成负 |
| EMA回踩(近似) n=311,666 | −0.34%（t=−14） | 基线本就负 | 无讨论价值 |

**四条硬结论**

1. **止损在这类信号上全是负贡献**。原因一致：这些信号的价值**全在右尾**，而止损恰好砍右尾。
   止损 −5% 最惨：超额从 +0.94% 直接打到 **−0.36%（t=−14.9）**，52% 的仓位被止损扫出。
2. **但止损确实把最大亏损从 −77.7% 压到 −24.4%**（−10% 止损），尾部压缩 **3.2 倍**，代价是 76% 的超额。
   所以正确的问法不是「要不要止损」，而是**「愿意用多少期望去换多小的尾部」**。
3. **移动止盈是最大杀手**（−1.14 ~ −1.70pt，t 低到 −86）。它系统性地把赢家提前砍掉——
   对一个靠右尾的策略，移动止盈等于自断现金流。
4. **「跌破 MA20 退出」对这类信号是逻辑错误**：深回踩平均持有 3.8 日、强跌反弹 1.6 日就出场，
   因为这些票买入时**本来就在 MA20 下方**，条件一开就触发。规则必须与信号的性质匹配。
5. **深回踩拖到 30 日反而归零**（+0.03%，t=0.3）：它的效应集中在 20 日内，拉长没有额外收益，只增加暴露。

**落地建议（写进 P5.6）**

> **止损不是为了提收益，是为了让你拿得住。**
> 采用 **−10% 硬止损**（单笔最大亏损锁在约 −24%）+ **小仓分散**（承接右尾）。
> 不要用移动止盈（会把右尾砍光）；不要用均线退出（与本类信号逻辑冲突）；不要超过 20 日持有。

以 1/6 仓位计，无止损时的 −77.7% 单笔对应账户 −13%；有 −10% 止损时约 −4%。**这才是止损的真实价值。**

### 3.4 组合层回测：连起来能不能拿住

前面所有结论都是「单笔横截面超额」，它回答「信号有没有效」，但不回答
「这套东西连起来能不能拿住」——最大回撤多深、空仓多久、能不能扛过熊市。

**方法**：日频事件驱动。信号日 t → t+1 开盘买入；10 个槽位等权；同日信号多于空槽时**随机取**（固定 seed，
用代码/市值/跌幅排序都会引入隐性偏差）；−10% 硬止损 + 20 日到期；每日收盘 mark-to-market。
基准取**全市场等权**而非沪深300——策略从全市场挑票，跟「随便买一篮子」比才公平。

**结果（2023-07-24 ~ 2026-11-03，794 个交易日）**

| 组合 | 总收益 | 年化 | 年化波动 | Sharpe | 最大回撤 | 回撤持续 | 日胜率 | 空仓 |
|---|---|---|---|---|---|---|---|---|
| 强跌反弹（−10%止损） | **+28.2%** | 7.9% | 20.4% | **0.39** | −26.4% | 174天 | **34.3%** | 31% |
| 强跌反弹（不止损） | +25.3% | 7.1% | 20.8% | 0.34 | −23.3% | 191天 | 36.6% | 35% |
| **+深回踩** | **−43.2%** | −15.9% | 27.1% | −0.59 | −57.8% | **767天** | 49.6% | 3% |
| 全市场等权（基准） | +23.7% | 6.7% | 26.1% | 0.26 | −32.4% | 210天 | **54.2%** | 0% |

**三条只有组合层才看得见的结论**

1. **★ 单笔最优 ≠ 组合最优：止损在组合层是正贡献。**
   单笔口径下止损把超额从 +0.94% 打到 +0.18%（§3.11）；但组合口径下，
   带止损的总收益 **25.3% → 28.2%**、买入笔数 468 → 594（周转更快）。
   原因：复利下「避免大亏」比「追求平均收益」更重要，且止损释放的现金能更快投入新信号。
   → **不要把单笔回测的结论直接照搬到资金曲线。**

2. **★ 深回踩一加进来，组合直接打穿（−43.2%，回撤持续 767 天）。**
   它的**信号密度远高于**强跌反弹（每天几十只 vs 十几只），把 10 个槽位全占满，
   而它在可交易池是负期望（§3.9.1）→ **负期望的高频信号会淹没正期望的低频信号**。
   反过来也成立：日胜率从 34.3% 升到 49.6%（看起来更舒服），但钱是亏的。
   → 已在 `daily_digest.py` 给深回踩加 `no_a` 标记：**不再进 A 档**，只留在 B 档作参考。

3. **日胜率 34.3% vs 市场 54.2% —— 这是这套策略最贵的成本。**
   你 2/3 的交易日是难受的，全靠少数几天赚回来（典型的右尾形状）。
   策略本身确实略优于市场（年化 +7.9% vs +6.7%，Sharpe 0.39 vs 0.26），但**优势只有 1.2 个百分点/年**。
   → 结论：这不是一套「能靠择时舒服赚钱」的系统。它的价值在**纪律**（选谁、多大仓、什么时候走），
     不在「找到好股票」。任何指望它显著跑赢的想法，数据都不支持。
