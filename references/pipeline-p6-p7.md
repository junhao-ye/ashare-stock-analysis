### P6 · Jev 语义判断（强制）

**为什么必须有一层语义判断**：确定性指标能算"是多少"，但算不出"这些数放在一起是否自相矛盾"。
典型例子——美的集团：ROE 21%、净利 +9.3%、站上全部均线，单看每一条都好；
但 **Q3 单季扣非 −15.7%、距 120 日高仅 −0.9%、缩量 1.11** —— 这三条与"净利增长"矛盾。
Jev 给出的可信度是 **4/100（矛盾/追高，置信 0.85）**，是确定性公式给不出的判断。

**两个 Score 问题**（都是有序刻度 0~4）：

| 问题 | 刻度 | 作用 |
|---|---|---|
| **信号可信度** | 矛盾/追高 → 偏弱 → 一般 → 较可信 → 高度可信 | 判断技术/基本面/资金/估值/预期五个维度是否互相印证 |
| **进场时机** | 不该进 → 偏早 → 观察 → 较成熟 → 成熟 | 判断时点成熟度（含回测期望、一票否决项） |

**读法**：
- 看**概率分布**优先于单一分数——分布集中才说明判断明确
- **置信度 <0.3 时结论不可用**（说明 state 内部矛盾，Jev 自己也不确定）
- Jev 只做一致性判断，**不预测涨跌**

#### ★★ 分数 × 置信 四象限（v4 新增，四票连跑的直接产物）

**只看分数会犯两类完全相反的错误。** 低分不等于"看清了很烂"，也可能是"根本没看清"。

| | 置信 ≥0.6（看得清） | 置信 <0.5（看不清） |
|---|---|---|
| **分数 ≤15** | **确定不该进** → 直接否决，无需复核 | **矛盾未解** → 必须人工复核，不可当否决用 |
| **分数 16~40** | 明确偏弱 → 观察，等条件改善 | 信号模糊 → 只做观察仓，不下注 |
| **分数 >40** | 明确偏强 → 进入 P5.5 选方案 | 谨慎偏强 → 需其他层佐证 |

四票落位：

| 标的 | 信号可信度 | 进场时机 | 象限 | 解读 |
|---|---|---|---|---|
| **特变电工** | **4**（置信 0.87） | **5**（置信 0.85） | 低分·高置信 | **看清楚了不该进**——基本面最好，但 RSI6 82 超买、T1 rr 仅 0.38，时点错 |
| 阳光电源 | 15（置信 0.81） | 37（置信 0.72） | 低分·高置信 | 确定偏弱 |
| 欣旺达 | 12（置信 0.79） | 18（置信 0.75） | 低分·高置信 | 确定最差 |
| **宁德时代** | **16**（置信 **0.44**） | **32**（置信 **0.38**） | 低分·**低置信** | **看不清**——好公司 vs 坏位置，状态自相矛盾，**必须人工复核** |

> **关键区别**：特变 4 分和宁德 16 分，看起来只差 12 分，
> 但特变是"**看清了不该进**"（置信 0.87），宁德是"**没看清**"（置信 0.38）。
> 前者可以直接执行否决；后者 Jev 自己都不确定，**必须回去看是哪个维度在打架**——
> 宁德的具体矛盾是：营收 +56.2%、净现金 +1799 亿（强）↔ 量比 1.00 缩量上涨、82% 筹码套牢（弱）。
>
> **操作规则：置信 <0.5 时，Jev 结论只能作为"提示"不能作为"裁决"，必须在报告里写明矛盾点。**

> **★ P6 补条（v4.6）：警惕「伪一致」——分数与自己的结论同向，但置信低到不可用。**
>
> 踩坑实录（中国船舶 600150，2026-11-10）：Jev 给出
> **信号可信度 15 分「偏弱」@ 0.50**、**进场时机 28 分「偏早」@ 0.27**。
> 而当时基于赔率（T1 rr 0.32 / T2 0.82）已得出"位置不对"的结论——
> **Jev 的 28 分"偏早"看起来完美佐证了它。**
>
> 但 **置信 0.27 < 0.3，按本流程该结论不可用**（分布 0:0.42 / 2:0.54，几乎对半）。
> 若拿它去支撑"偏早"，就是**用一个作废的数字给自己背书**——
> 这比"Jev 反对我"更危险，因为它**不会引起警觉**。反对意见会被审视，同向意见会被直接采纳。
>
> **固定纪律**：
> 1. **先查置信，再看分数**（顺序不能反）。置信 <0.3 → 该格直接标注"不可用"，**无论分数是否顺眼**。
> 2. **不能引用不可用的 Jev 结论作为结论的支撑**，只能在"数据缺口"里提一句。
> 3. 报告里必须写明"本结论不依赖 Jev"或"依赖的是哪一格、置信多少"。
> 4. 反过来也成立：**置信低而分数极端（0 分或 100 分）时，同样不可用**——极端分数 + 低置信 = 模型在硬选，不是看清了。

**实现**：`common/jev_stock.py`，凭据自动从 `.env` 读取；不可用时报告明确标注"本版未含语义判断层"，不静默跳过。

**调用要点（踩过的坑）**：
- `judge(facts)` 返回的 dict，**key 是中文题面**（`信号可信度` / `进场时机`），不是 `cred` / `timing`
- 渲染直接用 `format_lines(res)`，不要自己拼
- state 的字段名必须精确（见 `build_state` 的 key 列表），拼错会静默降级成"信息缺失"

#### ★★ P6 附则：模型适用性闸门 —— 非趋势型资产要「降级解读，但不豁免」（v4.3 新增）

> **踩坑实录（长江电力 600900 2026-11-09）**：Jev 给出
> **信号可信度 5.5/100「矛盾/追高」@ 置信 0.82**、时机 **27.0/100「偏早」@0.57** ——
> 六只票里最低分、最高置信。按四象限会直接落在"**确定不该进**"。
>
> 但 **Jev 的 criteria 隐含趋势/成长股假设**，其中三条对长江电力不成立：
>
> | Jev 视为危险 | 趋势股含义 | 红利/公用事业的实际含义 |
> |---|---|---|
> | 价格 99.4% 历史分位 | 超买、追高 | 10Y 国债从 3%+ 降到 1.58% 的**重估结果**，不是情绪 |
> | 营收 / 利润负增长 | 竞争力下滑 | **来水偏枯**（外生、可均值回归），电价还微升、FCF 持平 |
> | 获利盘 98.83% | 抛压巨大 | 71% 筹码锁在产业资本/险资，自由流通仅 29% |

**固定纪律**：

1. **进 P6 之前先判资产类型**。属于以下任一 → 标记「非趋势型」：
   红利/公用事业/类债券/REITs/高速公路/水电核电/银行保险等**以现金流与贴现率定价**、而非以成长定价的标的。
2. **非趋势型资产的「信号可信度」低分降级解读**：
   不得据此判"公司不行 / 该清仓"；它衡量的是**趋势交易信号的一致性**，不是资产质量。
3. **但「进场时机」不降级**：位置、赔率、动量这三项对任何资产都有效。
   长江电力的时机 27/100「偏早」与纯价差 rr 0.33 完全一致，**照单执行**。
4. **降级 ≠ 豁免**：Jev 指出的真实矛盾（价格历史最高、利润下滑、唯一目标价空间仅 5.6%、EB 供给未完）仍须逐条写进报告，
   不得用"模型不适用"一句话带过。
5. **P4 同步降级**：市值 > 3000 亿、前十大持股 > 60% 的标的，
   "主力/超大单/小单"分类的信噪比很低（长江电力 21 日主力 −10.12 亿仅占市值 0.14%），
   资金流数据只作辅助，**不作结论依据**。
6. **结论分两套写**（与 §P5 附则配套）：
   - **交易口径**：看纯价差 rr + 时机分 + 动量 → 本次「不进场」
   - **配置口径**：看含息 rr + 股债利差 + 分红承诺 + FCF 覆盖 → 本次「可持有，不在现价加仓」
   - 两套纪律（止损条件、退出条件、加仓触发）**必须分开列，禁止混用**。

### P7 · 横向对比（v4 新增，只做 ≥2 只时启用）

**为什么需要**：单票分析天然会给出"绝对判断"，但仓位是**相对选择**——
本流程真正要回答的不是"这只好不好"，而是"**在手上这几只里，钱应该放哪只**"。

四票连跑暴露的典型：每只单独看都有缺点，但一旦并排，
`特变（扣非 +9.44%、OCF/NP 2.09、PB 1.33、+DI 35）` 和 `欣旺达（OCF −25.38 亿、净负债 155 亿、负债率 74.1%）`
根本不在一个层级——**这个差距在单票报告里看不出来**。

#### 对比表模板（24 项，缺项写"缺"不写 0）

| 维度 | 指标 | 说明 |
|---|---|---|
| **成长** | 营收 YoY / 归母 YoY / **扣非 YoY** / 单季扣非 YoY | 四个都要，扣非和单季最不容易骗人 |
| **质量** | 毛利率及变动 / ROE / **OCF÷净利（双口径取差）** | OCF/NP 是最硬的照妖镜 |
| **安全** | 资产负债率 / 流动比率·速动比率 / 净现金或净负债 | 负債率 >70% 单独标红 |
| **估值** | PE(TTM) / **PB** / 一致预期 PE / 股息率 | PE 失效时看 PB（见 P3 规则三） |
| **位置** | 距 250 日高 / 站上几条均线 / **ADX + DI 方向** | 方向先于强度 |
| **情绪** | RSI6 / **量比** / ATR% | 量比 <1.1 = 缩量，涨也不可信 |
| **筹码** | 平均成本 / 获利盘% / 集中度90 | 获利盘 <30% = 深度套牢 |
| **资金** | **5 日 + 20 日主力** / 融资占比 / 北向季度变化 | 见 P4 三规则 |
| **赔率** | rr 四口径 / Jev 分数 + 置信 | 见 P5、P6 |

#### 排序原则（不是打分加总）

**不要做加权求和**——权重是拍脑袋的，加总会把"一票否决项"稀释掉。用**逐层筛选**：

```
第 1 层 否决：负债率 >70% 或 OCF 为负 或 四口径 rr 全 <1  → 出局
第 2 层 分层：扣非增速 >0 且 OCF/NP >1  → 进"可投池"
第 3 层 排序：在可投池里按「PB 低 + 位置不高 + rr 高」排
第 4 层 择时：Jev 分数低但置信高的，等条件改善；置信低的，人工复核
```

四票跑完的结果：

| 层级 | 标的 | 判定 |
|---|---|---|
| 出局 | 欣旺达 | OCF −25.38 亿、净负债 155 亿、负债率 74.1%、rr 全 <1 |
| 出局 | 阳光电源 | 营收 −26.4%、OCF/NP 0.55、rr 0.10 |
| 待复核 | 宁德时代 | 第 2 层通过（净现金 +1799 亿），但位置差 + Jev 低置信 |
| 可投（择时） | **特变电工** | 唯一四层全过；但 T1 rr 仅 0.20~0.38（**近目标不可做**），只能等回踩做 T2（2.62~5.01），且 RSI6 82 超买 → **等回踩，不追** |

> **结论的正确形态**：不是"买特变"，而是"**特变是唯一进入可投池的，但当前价位不是买点，
> 且必须接受 10% 止损 + 拿到中枢上沿**"。
> 这三句话差很远——第一句是推荐，后两句是**条件**。

#### 何时不做横向对比

- 只有 1 只票 → 跳过 P7，直接给单票结论
- 跨行业（如银行 vs 半导体）→ **只比位置和赔率，不比估值和质量**（PE/PB/毛利率不可比）
- 数量 >5 只 → 改用 P1 量化池排序，P7 只对比前 3~5 名
